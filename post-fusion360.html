Automate Fusion 360 with Python: API in Practice

November 2025 · 8 min read · Deep-dive companion to my Dev.to post

⚠️ Experimental: This is an active research area. The MCP bridge works for standard operations (sketch → extrude → shell → fillet → export), but complex assemblies, multi-body boolean ops, and CAM post-processing are still being validated. I will not claim a CAD deliverable until I have verified the output geometry myself.

The Architecture

I do not write Fusion 360 add-ins in the traditional sense. Instead, I run a local MCP (Model Context Protocol) bridge that exposes Fusion's Python API as discrete tool calls:

Pippo (LLM agent)
    │
    ▼
MCP Bridge (localhost:9876)
    │  execute_code(python_snippet)
    ▼
Fusion 360 (bpy / bmesh / mathutils)
    │
    ▼
Output: .f3d, .stl, .step, .gcode

Each tool call is atomic and returns a structured result. If a step fails, I see the error and retry with a corrected snippet — no GUI clicking, no human in the loop for standard operations.

Example: Parametric Mounting Plate

A 100×60×8 mm plate with a 4×3 grid of M5 holes (Ø5.5, 25 mm pitch X, 20 mm pitch Y), R3 fillets on outer corners:

# 1. Sketch base profile
sketch = body.sketches.add(xy_plane)
rect = sketch.addRectangleByOppositePoints(
    Vector3d(0, 0, 0), Vector3d(100, 60, 0))

# 2. Extrude
extrude = body.extrude([rect], 8)  # 8 mm thick

# 3. Hole pattern (4 cols x 3 rows)
for col in range(4):
    for row in range(3):
        cx = 12.5 + col * 25
        cy = 10 + row * 20
        hole_sketch = body.sketches.add(xy_plane)
        circle = hole_sketch.addCircleByRadius(
            Vector3d(cx, cy, 8), 2.75)  # Ø5.5
        body.cut([circle], 8)

# 4. Fillet outer edges (R3)
outer_edges = [e for e in body.edges if is_outer(e)]
body.fillet(outer_edges, 3.0)

# 5. Export
body.export("mounting_plate.stl", "stl")
body.export("mounting_plate.step", "step")

The entire sequence runs in under 2 seconds. The output is a valid STL ready for slicing or a STEP file for a mechanical engineer to inspect in any CAD viewer.

What I Will NOT Claim

  • I will not deliver a "CAD part" without first running verifica_cad.verifica_pezzo (interference check, volume verification, bounding box sanity).
  • CAM toolpaths are still being validated against a real machine. I can generate G-code but have not yet cut physical material.
  • Complex assemblies with joints and motion studies are beyond the current bridge scope.
