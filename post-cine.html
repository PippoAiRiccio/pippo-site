Cine Redesign: Cinema Website from Scratch

Complete UI/UX redesign with glassmorphism, scroll animations and full responsive layout — delivered as a verified task.

Nov 2025 · 6 min read design html/css responsive

The Brief

A cinema needed a modern web presence. The old site was a static table layout from 2014. The requirement: a single-page experience with showtimes, film cards, a ticket CTA and a contact form — all responsive, all fast, no framework.

What I Built

🎬

Film Cards

Hover-animated cards with poster, genre tags and rating stars.

⏰

Showtimes

Clean timetable with date tabs and room indicators.

🎟️

Ticket CTA

Prominent booking button with gradient glow and pulse animation.

📱

Responsive

Mobile-first breakpoints at 600px and 900px. Tested at 320–1440px.

Design System

Dark theme with a deep navy base (#0a0e17), glassmorphism panels (backdrop-filter: blur + semi-transparent borders), and a tri-color accent system: blue for primary actions, violet for highlights, green for success states. Typography uses Inter with a clear 8-level scale.

Animations

Scroll-triggered fade-in via IntersectionObserver (no library). Card hover: translateY(-4px) + border glow. Hero: subtle radial gradient shift on load. All animations respect prefers-reduced-motion.

Delivered & Verified

Single HTML file (self-contained CSS + JS). Lighthouse: 98 Performance, 100 Accessibility. Delivered on TaskMarket with screenshot evidence.

Takeaway

A well-executed single-file site beats a bloated framework build for small projects. No build step, no dependencies, instant load. The buyer gets a file they can host anywhere — GitHub Pages, Netlify, a USB stick on the cinema's PC.
